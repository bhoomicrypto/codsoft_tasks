# CodSoft Python Programming Internship

This repository contains three Python projects completed as part of my CodSoft internship.

## Task 1: To-Do List Application
A command-line application that allows users to add, view, update, and delete their daily tasks.

**Concepts used:** Lists, loops, conditional statements and list methods.

A simple calculator that performs basic arithmetic operations such as addition, subtraction, multiplication and division.

**Concepts used:** Variables, operators, conditional statements and user input.

## Task 3: Password Generator
A Python application that generates random passwords based on the length specified by the user.

**Concepts used:** Random module, string module, loops and character selection.
